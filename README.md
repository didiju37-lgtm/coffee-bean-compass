# 홀빈 취향 대시보드

월별 커피 원두(홀빈) 판매와 고객 반응을 비교하고, 개인 취향과 예산에 맞는 원두를 추천하는 브라우저 대시보드입니다.

## 바로 사용하기

https://didiju37-lgtm.github.io/coffee-bean-compass/

## 주요 기능

- 월별 판매량, 평점, 긍정 반응, 재구매 의향 비교
- 판매 추이를 보여주는 월별 차트
- 추출 방식, 예산, 배전도, 산미, 바디, 선호 향미 설정
- 추천 점수와 추천 이유 표시
- CSV/XLSX 일괄 업로드와 한 건 직접 입력
- CSV 입력 양식 다운로드와 전체 데이터 내보내기
- 브라우저 로컬 저장

## 추천 점수

추천 순위는 다음 네 요소로 계산합니다.

- 취향 적합도 50%: 추출 방식, 배전도, 산미, 바디, 향미
- 고객 반응 25%: 평점, 긍정 반응, 재구매 의향
- 판매 흐름 15%: 같은 원두의 직전 기록 대비 판매 증감
- 가격 적합도 10%: 설정한 100g 예산과 실제 가격 비교

## 데이터 형식

`CSV 양식` 버튼으로 바로 사용할 수 있는 입력 파일을 받을 수 있습니다.

| 열 | 필수 | 설명 |
| --- | --- | --- |
| 월 | 필수 | `YYYY-MM` 형식 |
| 원두명 | 필수 | 상품 또는 원두 이름 |
| 로스터리 | 필수 | 판매처 또는 브랜드 |
| 판매수량 | 권장 | 월 판매 봉 수 |
| 평점 | 권장 | 0~5점 |
| 가격·중량 | 선택 | 100g 가격 계산에 사용 |
| 긍정반응·재구매의향 | 선택 | 0~100% |
| 로스팅·산미·바디 | 선택 | 각각 1~5 |
| 향미 | 선택 | 쉼표로 구분 |

## 개인정보 보호

입력한 파일과 데이터는 별도 서버로 전송되지 않습니다. 브라우저의 로컬 저장소에만 보관되므로 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 자동으로 이전되지 않습니다.

## 로컬 실행

별도 빌드 없이 정적 웹 서버로 실행할 수 있습니다.

```powershell
python -m http.server 4174
```

브라우저에서 `http://localhost:4174`로 접속합니다.
